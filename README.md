# Project Overview

This project is a responsive website clone for GTG Perfumes, created as part of a UI Developer assessment for Cube. The implementation showcases modern web development practices with a focus on pixel-perfect design, responsive layouts, and smooth user interactions.


# Live Demo
🌐 Live Website: https://gtg-fragrances-for-you.netlify.app/

#  Features Implemented

- **Header with Responsive Navigation**
- **Hero Section**
- **cart Showcase Section**
- **Our Collection Section**
- **Comparison Table Section**
- **Footer**


# Core Features
- **Responsive Design** - Works on all devices (mobile, tablet, desktop)
- **Modern UI/UX** - Clean, intuitive interface with smooth animations
- **Fast Performance** - Optimized assets and efficient code
- **Accessibility** - WCAG compliant with keyboard navigation

# Key Technical Skills Demonstrated
- **Responsive Web Design** - Mobile-first approach with breakpoints
- **CSS Architecture** - Modular, maintainable stylesheets
- **JavaScript Interactivity** - DOM manipulation and event handling
- **Cross-browser Compatibility** - Consistent experience across platforms
